# FeuerwerkAgent Vue前端

## 🚀 快速开始

### 启动前端开发服务器
```bash
npm run dev
```

### 访问应用
打开浏览器访问: `http://localhost:5173`

## 📋 功能特性

### ✨ 真正的流式响应
- 逐字显示DeepSeek AI回复
- 实时滚动到最新内容
- 流畅的打字效果
- 输入状态指示器

### 💬 智能对话
- 基于DeepSeek V4 Pro
- 支持多轮对话
- 消息历史记录
- 时间戳显示

### 🔍 联网搜索
- 国内搜索引擎（百度、360、搜狗）
- AI智能摘要
- 搜索结果展示
- 来源标注

## 🎨 使用说明

### AI对话
1. 在输入框输入消息
2. 按Enter或点击"发送"按钮
3. 观察AI逐字回复
4. 支持多轮对话

### 联网搜索
1. 在搜索框输入关键词
2. 按Enter或点击"搜索"按钮
3. 查看AI摘要和搜索结果

## 🛠️ 技术栈

- **Vue 3**: Composition API
- **Vite**: 快速开发服务器
- **流式处理**: Fetch API + ReadableStream
